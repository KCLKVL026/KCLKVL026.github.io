## 🔌 电路分析基础辅助教学

我借助 Deepseek V3.2 开发了一套面向电气、电子、自动化等相关专业的**交互式仿真教学工具**，旨在通过动态可视化帮助理解电路核心概念。所有模块均支持参数实时调节、波形/曲线即时更新，适合课堂演示与学生自主探索。

👉 **立即体验**：[电路分析基础辅助教学主页](https://kclkvl026.github.io/Circuit_Analysis/)

该主页现包含 **17 个交互仿真模块**，按知识体系分为以下五组：

### 1. 正弦特性与功率特性
| 模块名称 | 简介 |
|---------|------|
| RLC正弦特性 | 正弦稳态下 RLC 元件的阻抗与相位关系 |
| 电阻正弦特性 | 纯电阻电路交流响应，电压电流完全同相 |
| 电容正弦特性 | 容抗随频率变化，电流超前电压 90° |
| 电感正弦特性 | 感抗与频率成正比，电流滞后电压 90° |
| LC功率曲线 | 电感与电容之间的无功能量交换，有功/无功功率波形 |

### 2. 频率特性（滤波器与谐振）
| 模块名称 | 简介 |
|---|---|
| RC低通滤波器 | 允许低频信号通过，展示截止频率与 -3dB 点 |
| RC高通滤波器 | 衰减低频成分，相位超前特性可视化 |
| 带通滤波器 | 允许特定频段信号通过，中心频率与带宽可调 |
| 带阻滤波器 | 抑制特定频段信号，陷波特性清晰 |
| RLC串联谐振频率特性 | 谐振尖峰、品质因数 Q 对频率选择性的影响 |
| RLC并联谐振频率特性 | 谐振尖峰、品质因数 Q 对频率选择性的影响 |

### 3. 瞬态分析
| 模块名称 | 简介 |
|---|---|
| 电容充放电特性 | RC 电路暂态过程，时间常数 τ 对指数曲线的影响 |
| 电感充放电特性 | RL 电路暂态过程，时间常数 τ 对指数曲线的影响 |

### 4. 非正弦周期信号的傅里叶级数展开
| 模块名称 | 简介 |
|---|---|
| 方波的傅里叶级数展开 | 方波分解为谐波叠加，吉布斯现象与频谱可视化 |
| 三角波的傅里叶级数展开 | 三角波谐波幅度随频率平方衰减，收敛更快 |
| 梯形波的傅里叶级数展开 | 梯形波频谱特性，平顶与斜边对谐波衰减的影响 |

### 5. 三相电路
| 模块名称 | 简介 |
|---|---|
| 三相对称电源电压曲线 | 三相正弦电压幅值相等、相位互差 120°，对称性演示 |

每个模块均为独立 HTML 页面，使用现代 Web 技术（Chart.js、TailwindCSS、KaTeX 等），在电脑或平板上均可流畅运行。

## 🛠️ 技术栈

- HTML5 / CSS3 / JavaScript (ES6)
- TailwindCSS (样式框架)
- Chart.js (图表绘制)
- KaTeX (数学公式渲染)
