7.1 动态电路的暂态过程及换路定则

7.1.1 动态电路的基本概念

  • 动态电路：含有电容或电感等储能元件的电路
  • 暂态过程（过渡过程）：电路从一个稳态过渡到另一个稳态的中间过程
  • 产生原因：储能元件的能量不能突变（能量的积累和释放需要时间）
  • 稳态：电路中各物理量达到稳定的状态（直流稳态或交流稳态）
  • 换路：电路结构或参数突然发生变化（开关动作、参数突变等）

7.1.2 换路定则

核心定理 换路定则

内容：在换路瞬间（$t = 0$），电容电压和电感电流不能突变

$$u_C(0^+) = u_C(0^-) \qquad i_L(0^+) = i_L(0^-)$$

物理本质：能量不能突变（$W_C = \frac{1}{2}Cu_C^2$，$W_L = \frac{1}{2}Li_L^2$）

推论：

  • 电容电流可以突变
  • 电感电压可以突变
  • 电阻的电压和电流都可以突变
Procedure 初始值的确定步骤
1
求 $t = 0^-$ 时的
$u_C(0^-)$ 和 $i_L(0^-)$
（稳态分析）
2
由换路定则得
$u_C(0^+)$ 和 $i_L(0^+)$
3
画 $t = 0^+$ 时的
等效电路（电容用电压源替代，电感用电流源替代）
4
求其他物理量
的初始值

7.2 一阶电路的零输入响应

RC 电路 一阶RC电路的零输入响应

电路结构：已充电的电容C通过电阻R放电

$$RC\frac{du_C}{dt} + u_C = 0$$ $$u_C(t) = u_C(0^+)e^{-t/\tau}$$
  • 时间常数：$\tau = RC$（单位：秒）
  • 电容电压按指数规律衰减到零
  • $\tau$ 越大，衰减越慢
  • 经过 $3\tau \sim 5\tau$ 后，可认为暂态过程基本结束
$$i(t) = -\frac{u_C(0^+)}{R}e^{-t/\tau}$$

放电电流：初始最大，最终为零

RL 电路 一阶RL电路的零输入响应

电路结构：已通电的电感L通过电阻R释放能量

$$L\frac{di_L}{dt} + Ri_L = 0$$ $$i_L(t) = i_L(0^+)e^{-t/\tau}$$
  • 时间常数：$\tau = L/R$（单位：秒）
  • 电感电流按指数规律衰减到零
  • 电感电压 $u_L(t) = -Ri_L(0^+)e^{-t/\tau}$（突变）

7.3 一阶电路的零状态响应

RC 电路 一阶RC电路的零状态响应

电路结构：未充电的电容C接入直流电压源 $U_s$

$$RC\frac{du_C}{dt} + u_C = U_s$$ $$u_C(t) = U_s(1 - e^{-t/\tau}), \quad \tau = RC$$
  • 电容电压从零按指数规律上升到 $U_s$
  • 充电电流 $i(t) = \frac{U_s}{R}e^{-t/\tau}$，初始最大，最终为零
  • 电容相当于开路（直流稳态）
RL 电路 一阶RL电路的零状态响应

电路结构：电流为零的电感L接入直流电压源 $U_s$（串联电阻R）

$$L\frac{di_L}{dt} + Ri_L = U_s$$ $$i_L(t) = \frac{U_s}{R}(1 - e^{-t/\tau}), \quad \tau = L/R$$
  • 电感电流从零按指数规律上升到 $U_s/R$
  • 电感电压 $u_L(t) = U_s e^{-t/\tau}$，初始最大，最终为零
  • 电感相当于短路（直流稳态）

7.4 一阶电路的全响应和三要素法

7.4.1 一阶电路的全响应

Definition 全响应

定义：零输入响应与零状态响应之和

$$\text{全响应} = \text{零输入响应} + \text{零状态响应}$$

分解方式二：稳态分量 + 暂态分量

$$\text{全响应} = \text{稳态分量} + \text{暂态分量}$$

RC电路全响应：

$$u_C(t) = U_s + [u_C(0^+) - U_s]e^{-t/\tau}$$
  • $U_s$：稳态分量（终值）
  • $[u_C(0^+) - U_s]e^{-t/\tau}$：暂态分量（衰减项）
  • 物理意义：全响应反映了电路从初始状态到稳态的完整变化过程

7.4.2 一阶电路的三要素法

Key Method 三要素法

三要素：

  • 初始值 $f(0^+)$：换路后瞬间的值
  • 稳态值 $f(\infty)$：$t \to \infty$ 时的稳态值
  • 时间常数 $\tau$：决定暂态过程的快慢

通用公式：

$$f(t) = f(\infty) + [f(0^+) - f(\infty)]e^{-t/\tau}$$

适用范围：任何一阶线性电路的全响应

适用：一阶线性电路 $\tau = R_{eq}C$ 或 $\tau = L/R_{eq}$
Procedure 三要素法求解步骤
1
求 $f(0^+)$
用换路定则和
$t=0^+$ 等效电路
2
求 $f(\infty)$
电容开路、电感短路
求直流稳态解
3
求 $\tau$
独立源置零，求
$R_{eq}$
4
代入公式
$f(t) = f(\infty) + [f(0^+) - f(\infty)]e^{-t/\tau}$

7.5 阶跃函数和阶跃响应

7.5.1 阶跃函数
$$\varepsilon(t) = \begin{cases} 0, & t < 0 \\ 1, & t > 0 \end{cases}$$
  • 延迟阶跃：$\varepsilon(t - t_0)$ 在 $t = t_0$ 时刻跳变
  • 幅值阶跃：$K\varepsilon(t)$ 幅值为K
  • 物理意义：表示开关在 $t=0$ 时刻闭合（或断开）的动作
7.5.2 阶跃响应

定义：一阶电路在阶跃输入下的零状态响应

RC电路阶跃响应
$u_C(t) = U_s(1-e^{-t/\tau})\varepsilon(t)$
RL电路阶跃响应
$i_L(t) = \frac{U_s}{R}(1-e^{-t/\tau})\varepsilon(t)$

意义：阶跃响应是分析更复杂输入的基础

7.6 冲激函数和冲激响应

7.6.1 冲激函数
$$\delta(t) = \begin{cases} 0, & t \neq 0 \\ \infty, & t = 0 \end{cases}, \quad \int_{-\infty}^{+\infty}\delta(t)dt = 1$$
  • 筛选性质：$\int_{-\infty}^{+\infty}f(t)\delta(t)dt = f(0)$
  • 物理意义：表示极短时间内作用的极大力（如锤击、雷击）
  • 与阶跃函数的关系：$\delta(t) = d\varepsilon(t)/dt$
7.6.2 冲激响应

定义：电路在单位冲激函数 $\delta(t)$ 作用下的零状态响应

求法：

  • 方法一：直接求解微分方程
  • 方法二：利用阶跃响应求导（对一阶电路）
$$h(t) = \frac{1}{RC}e^{-t/RC}\varepsilon(t)$$

RC电路冲激响应

冲激响应 = 阶跃响应的导数 与频率响应互为傅里叶变换对

7.7 二阶电路的零输入响应

Overview 二阶电路基本方程

电路结构：含有两个储能元件（如RLC串联或并联电路）

微分方程：二阶常系数线性微分方程（RLC串联为例）

$$LC\frac{d^2u_C}{dt^2} + RC\frac{du_C}{dt} + u_C = 0$$

特征方程：

$$s^2 + \frac{R}{L}s + \frac{1}{LC} = 0$$

特征根：

$$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$$
  • $\alpha = R/(2L)$：衰减系数
  • $\omega_0 = 1/\sqrt{LC}$：固有角频率
