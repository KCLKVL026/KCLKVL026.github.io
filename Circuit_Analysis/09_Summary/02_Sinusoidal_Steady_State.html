5.1 正弦量的基本概念

5.1.1 频率与周期

  • 周期 T：正弦量完成一次周期性变化所需的时间，单位：秒（s）
  • 频率 f：单位时间内正弦量完成周期性变化的次数，$f = 1/T$，单位：赫兹（Hz）
  • 角频率 ω：正弦量相位变化的速度，$\omega = 2\pi f = 2\pi/T$，单位：弧度/秒（rad/s）
  • 工频：我国电力系统标准频率为50Hz，即 $\omega = 100\pi \approx 314$ rad/s

5.1.2 振幅与有效值

  • 瞬时值：$i(t) = I_m \sin(\omega t + \varphi)$
  • 振幅（最大值） $I_m$：正弦量的最大值
  • 有效值（RMS值）：与正弦量产生相同热效应的直流值 $$I = \frac{I_m}{\sqrt{2}} \approx 0.707 I_m$$
  • 有效值的意义：交流电表的读数通常为有效值；电气设备的额定值也用有效值表示

5.1.3 初相位

  • 相位：$\omega t + \varphi$，表示正弦量在某一时刻的状态
  • 初相位 $\varphi$：$t=0$ 时刻的相位角，$|\varphi| \leq \pi$
  • 物理意义：反映正弦量在计时起点时的状态
  • 相位差：两个同频率正弦量的初相位之差，$\varphi = \varphi_1 - \varphi_2$
    • $\varphi > 0$：u 超前 i（或 i 滞后 u）
    • $\varphi < 0$：u 滞后 i（或 i 超前 u）
    • $\varphi = 0$：u 与 i 同相
    • $\varphi = \pi$：u 与 i 反相

5.2 正弦量的相量表示法

5.2.1 复数及其运算

  • 复数表示：
    • 代数形式：$A = a + jb$（$j^2 = -1$）
    • 指数形式：$A = |A|e^{j\theta}$
    • 极坐标形式：$A = |A|\angle\theta$
  • 基本运算：
    • 加减法：实部与实部相加减，虚部与虚部相加减
    • 乘除法：模相乘除，辐角相加减
    • 共轭复数：$\bar{A} = a - jb = |A|\angle(-\theta)$

5.2.2 相量的概念

  • 定义：用复数来表示正弦量的振幅（或有效值）和初相位
  • 振幅相量：$\dot{I}_m = I_m e^{j\varphi} = I_m\angle\varphi$
  • 有效值相量：$\dot{I} = I e^{j\varphi} = I\angle\varphi$（工程中更常用）
  • 对应关系：$i(t) = I_m \sin(\omega t + \varphi) \leftrightarrow \dot{I}_m = I_m\angle\varphi$
  • 注意：相量只能表示同频率的正弦量；不同频率的正弦量不能用同一相量表示

5.2.3 相量图

  • 定义：在复平面上用有向线段表示相量的图形
  • 画法：以坐标原点为起点，长度表示有效值（或振幅），角度表示初相位
  • 用途：直观表示各正弦量之间的相位关系；辅助进行相量的加减运算

5.2.4 相量的运算性质

  • 时域微分对应相量乘法：$\frac{d}{dt} \rightarrow j\omega$
  • 时域积分对应相量除法：$\int dt \rightarrow \frac{1}{j\omega}$
  • 同频率正弦量的线性运算：可用相量直接进行加减

5.3 两类约束的相量形式

5.3.1 基尔霍夫定律的相量形式

  • KCL的相量形式：$\sum \dot{I} = 0$（流入节点的相量电流之和为零）
  • KVL的相量形式：$\sum \dot{U} = 0$（沿回路的相量电压之和为零）
  • 说明：相量形式的KCL和KVL与直流电路形式完全相同，但运算对象是复数

5.3.2 电路元件伏安关系的相量形式

5.4 无源单口网络的阻抗

阻抗 5.4.1 阻抗的概念
$$Z = \frac{\dot{U}}{\dot{I}} = R + jX = |Z|\angle\varphi_z$$
  • 电阻部分（实部）：$R = |Z|\cos\varphi_z$
  • 电抗部分（虚部）：$X = |Z|\sin\varphi_z$
  • 阻抗模：$|Z| = \sqrt{R^2 + X^2}$
  • 阻抗角：$\varphi_z = \arctan(X/R)$（即电压超前电流的角度）
导纳：$Y = 1/Z = G + jB$

5.4.2 阻抗的串联与并联

  • 串联：$Z_{eq} = Z_1 + Z_2 + \cdots + Z_n$
  • 并联：$\frac{1}{Z_{eq}} = \frac{1}{Z_1} + \frac{1}{Z_2} + \cdots + \frac{1}{Z_n}$
  • 分压公式：$\dot{U}_k = \frac{Z_k}{Z_1+Z_2+\cdots+Z_n} \cdot \dot{U}$
  • 分流公式：$\dot{I}_k = \frac{Z_{eq}}{Z_k} \cdot \dot{I}$

5.4.3 电路的相量模型

  • 建立方法：将电路中各元件用其相量模型替换
    • 电阻 → $R$
    • 电感 → $j\omega L$
    • 电容 → $1/(j\omega C)$
    • 电压源 → $\dot{U}_s$，电流源 → $\dot{I}_s$
  • 特点：相量模型中各量都是复数，分析方法与直流电阻电路相同

5.6.6 电路功率因数的提高

功率因数 并联电容补偿

意义：减小线路电流，降低传输损耗，提高设备利用率

方法：并联适当的电容（补偿感性负载的无功功率）

$$C = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2}$$
  • $\varphi_1$：补偿前的功率因数角
  • $\varphi_2$：补偿后的目标功率因数角
  • $P$：负载有功功率
  • $U$：电源电压有效值

  • $\omega \gg \omega_c$：$|H| \to 0$，信号被抑制

5.8 谐振电路

串联谐振 5.8.1 串联谐振

定义：R-L-C串联电路中，当感抗等于容抗时发生的谐振

$$\omega_0 L = \frac{1}{\omega_0 C} \quad \Rightarrow \quad \omega_0 = \frac{1}{\sqrt{LC}}$$
  • 阻抗最小：$Z = R$（纯电阻）
  • 电流最大：$I = U/R$
  • 电压与电流同相（功率因数 = 1）
  • 电感电压与电容电压大小相等、方向相反，可能远大于电源电压
  • 品质因数：$Q = \dfrac{\omega_0 L}{R} = \dfrac{1}{\omega_0 CR}$
  • Q越大，谐振曲线越尖锐，选择性越好
并联谐振 5.8.2 并联谐振

定义：R-L-C并联电路中发生的谐振

$$\omega_0 = \frac{1}{\sqrt{LC}}$$
  • 导纳最小（阻抗最大）
  • 总电流最小
  • 各支路电流可能远大于总电流
  • 电路呈纯电阻性
  • 品质因数：$Q = R\sqrt{\dfrac{C}{L}} = \dfrac{R}{\omega_0 L} = \omega_0 RC$

串联谐振 vs 并联谐振

6.1 耦合电感

6.1.1 互感

  • 定义：当一个线圈中的电流变化时，不仅在本线圈中产生感应电压，还在相邻线圈中产生感应电压的现象
  • 互感系数 M：$M_{12} = M_{21} = M$
  • 耦合系数：$k = M/\sqrt{L_1 L_2}$，$0 \leq k \leq 1$
    • $k = 0$：无耦合
    • $k = 1$：全耦合（理想情况）

6.1.2 耦合电感的伏安关系

伏安关系 时域与相量形式

电压方程：

$$u_1 = L_1\frac{di_1}{dt} \pm M\frac{di_2}{dt}$$ $$u_2 = L_2\frac{di_2}{dt} \pm M\frac{di_1}{dt}$$

M前的正负号取决于电流方向与同名端的关系（同侧取正，异侧取负）

相量形式：

$$\dot{U}_1 = j\omega L_1\dot{I}_1 \pm j\omega M\dot{I}_2$$ $$\dot{U}_2 = j\omega L_2\dot{I}_2 \pm j\omega M\dot{I}_1$$

6.1.3 耦合电感的同名端

  • 定义：当两线圈电流同时从同名端流入（或流出）时，互感磁通与自感磁通方向相同
  • 判断方法：
    • 标记法：用"•"或"*"标记同名端
    • 右手螺旋法则：根据绕向判断
  • 作用：确定互感电压的正负号

6.1.4 耦合电感的等效电路模型

  • 去耦等效：将耦合电感用无互感的等效电路替代
  • T型等效（同名端相连时）：等效电感分别为 $L_1-M$、$L_2-M$、$M$
  • 应用：将含互感的电路转化为无互感电路，便于分析

6.3 空心变压器

空心变压器 电路模型与反映阻抗

结构：两个耦合线圈绕在同一非铁磁材料骨架上

  • 原边：电压源 $\dot{U}_s$、电阻 $R_1$、电感 $L_1$
  • 副边：电阻 $R_2$、电感 $L_2$，互感 $M$
  • 反映阻抗：副边对原边的影响可用一个反映阻抗 $Z_r = (\omega M)^2/Z_{22}$ 表示

6.4 理想变压器

6.4.1 理想变压器的主要性能

理想变压器 主要性能参数

理想化条件：$k = 1$（全耦合），$L_1, L_2 \to \infty$，无损耗

$$n = \frac{N_1}{N_2} \quad \text{（变比：匝数比）}$$
  • 电压关系：$u_1/u_2 = n$
  • 电流关系：$i_1/i_2 = -1/n$（负号表示电流方向相反）
  • 阻抗变换：$Z_{in} = n^2 Z_L$（副边阻抗 $Z_L$ 折算到原边为 $n^2 Z_L$）
  • 功率关系：输入功率等于输出功率，$u_1 i_1 + u_2 i_2 = 0$
