8.1 双口网络的基本概念

  • 定义：具有两个端口（每个端口由一对端子组成）的网络
  • 端口条件：每个端口的一对端子中，流入一个端子的电流等于从另一个端子流出的电流
  • 与四端网络的区别：四端网络的四个端子电流不一定满足端口条件
  • 端口变量：
    • 输入端口（端口1）：电压 $\dot{U}_1$，电流 $\dot{I}_1$
    • 输出端口（端口2）：电压 $\dot{U}_2$，电流 $\dot{I}_2$
  • 参考方向：通常规定电流从端口的正极性端子流入
  • 线性双口网络：内部不含独立源，元件为线性
  • 对称双口网络：两个端口的电气特性完全相同
  • 倒易双口网络：满足互易定理，$z_{12} = z_{21}$（或 $y_{12} = y_{21}$）

8.2 四种参数方程一览

Z 参数
阻抗方程
以电流为自变量，用电压表示。开路条件下测量。
$\dot{U} = \mathbf{Z}\dot{I}$
互易: $z_{12}=z_{21}$ 对称: $z_{11}=z_{22}$
Y 参数
导纳方程
以电压为自变量，用电流表示。短路条件下测量。$\mathbf{Y}=\mathbf{Z}^{-1}$
$\dot{I} = \mathbf{Y}\dot{U}$
互易: $y_{12}=y_{21}$ 对称: $y_{11}=y_{22}$
T 参数
传输方程
描述输入到输出的信号传输过程，适合级联分析。
$\begin{bmatrix}\dot{U}_1\\\dot{I}_1\end{bmatrix} = \mathbf{T}\begin{bmatrix}\dot{U}_2\\-\dot{I}_2\end{bmatrix}$
互易: $AD-BC=1$ 对称: $A=D$
H 参数
混合方程
混合使用电压和电流作自变量。晶体管等效电路常用。
$\begin{bmatrix}\dot{U}_1\\\dot{I}_2\end{bmatrix} = \mathbf{H}\begin{bmatrix}\dot{I}_1\\\dot{U}_2\end{bmatrix}$
互易: $h_{12}=-h_{21}$ 对称: $h_{11}h_{22}-h_{12}h_{21}=1$
Z 参数 阻抗方程详解
$$\dot{U}_1 = z_{11}\dot{I}_1 + z_{12}\dot{I}_2 \qquad \dot{U}_2 = z_{21}\dot{I}_1 + z_{22}\dot{I}_2$$ $$\begin{bmatrix}\dot{U}_1\\\dot{U}_2\end{bmatrix} = \mathbf{Z}\begin{bmatrix}\dot{I}_1\\\dot{I}_2\end{bmatrix}$$

参数物理意义（开路参数）：

  • $z_{11} = \dfrac{\dot{U}_1}{\dot{I}_1}\bigg|_{\dot{I}_2=0}$ — 端口2开路时端口1的输入阻抗
  • $z_{12} = \dfrac{\dot{U}_1}{\dot{I}_2}\bigg|_{\dot{I}_1=0}$ — 端口1开路时的转移阻抗
  • $z_{21} = \dfrac{\dot{U}_2}{\dot{I}_1}\bigg|_{\dot{I}_2=0}$ — 端口2开路时的转移阻抗
  • $z_{22} = \dfrac{\dot{U}_2}{\dot{I}_2}\bigg|_{\dot{I}_1=0}$ — 端口1开路时端口2的输入阻抗

测量方法：分别将端口1或端口2开路，测量电压和电流。

互易条件：$z_{12} = z_{21}$ 对称条件：$z_{11} = z_{22}$
Y 参数 导纳方程详解
$$\dot{I}_1 = y_{11}\dot{U}_1 + y_{12}\dot{U}_2 \qquad \dot{I}_2 = y_{21}\dot{U}_1 + y_{22}\dot{U}_2$$ $$\begin{bmatrix}\dot{I}_1\\\dot{I}_2\end{bmatrix} = \mathbf{Y}\begin{bmatrix}\dot{U}_1\\\dot{U}_2\end{bmatrix}$$

参数物理意义（短路参数）：

  • $y_{11} = \dfrac{\dot{I}_1}{\dot{U}_1}\bigg|_{\dot{U}_2=0}$ — 端口2短路时端口1的输入导纳
  • $y_{12} = \dfrac{\dot{I}_1}{\dot{U}_2}\bigg|_{\dot{U}_1=0}$ — 端口1短路时的转移导纳
  • $y_{21} = \dfrac{\dot{I}_2}{\dot{U}_1}\bigg|_{\dot{U}_2=0}$ — 端口2短路时的转移导纳
  • $y_{22} = \dfrac{\dot{I}_2}{\dot{U}_2}\bigg|_{\dot{U}_1=0}$ — 端口1短路时端口2的输入导纳
与Z参数关系：$\mathbf{Y} = \mathbf{Z}^{-1}$ 互易：$y_{12}=y_{21}$ 对称：$y_{11}=y_{22}$
T 参数 传输方程详解
$$\dot{U}_1 = A\dot{U}_2 - B\dot{I}_2 \qquad \dot{I}_1 = C\dot{U}_2 - D\dot{I}_2$$ $$\begin{bmatrix}\dot{U}_1\\\dot{I}_1\end{bmatrix} = \mathbf{T}\begin{bmatrix}\dot{U}_2\\-\dot{I}_2\end{bmatrix}$$

参数物理意义：

  • $A = \dfrac{\dot{U}_1}{\dot{U}_2}\bigg|_{\dot{I}_2=0}$ — 开路电压传输比
  • $B = -\dfrac{\dot{U}_1}{\dot{I}_2}\bigg|_{\dot{U}_2=0}$ — 短路转移阻抗
  • $C = \dfrac{\dot{I}_1}{\dot{U}_2}\bigg|_{\dot{I}_2=0}$ — 开路转移导纳
  • $D = -\dfrac{\dot{I}_1}{\dot{I}_2}\bigg|_{\dot{U}_2=0}$ — 短路电流传输比

特点：T参数适合描述信号从输入到输出的传输过程。

互易条件：$AD - BC = 1$ 对称条件：$A = D$
H 参数 混合方程详解
$$\dot{U}_1 = h_{11}\dot{I}_1 + h_{12}\dot{U}_2 \qquad \dot{I}_2 = h_{21}\dot{I}_1 + h_{22}\dot{U}_2$$ $$\begin{bmatrix}\dot{U}_1\\\dot{I}_2\end{bmatrix} = \mathbf{H}\begin{bmatrix}\dot{I}_1\\\dot{U}_2\end{bmatrix}$$

参数物理意义：

  • $h_{11} = \dfrac{\dot{U}_1}{\dot{I}_1}\bigg|_{\dot{U}_2=0}$ — 端口2短路时的输入阻抗
  • $h_{12} = \dfrac{\dot{U}_1}{\dot{U}_2}\bigg|_{\dot{I}_1=0}$ — 端口1开路时的反向电压传输比
  • $h_{21} = \dfrac{\dot{I}_2}{\dot{I}_1}\bigg|_{\dot{U}_2=0}$ — 端口2短路时的正向电流传输比
  • $h_{22} = \dfrac{\dot{I}_2}{\dot{U}_2}\bigg|_{\dot{I}_1=0}$ — 端口1开路时的输出导纳

特点：H参数在晶体管等效电路中广泛使用。

互易条件：$h_{12} = -h_{21}$ 对称条件：$h_{11}h_{22} - h_{12}h_{21} = 1$
