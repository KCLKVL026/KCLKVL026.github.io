反相积分器 · \(V_{out}(t) = -\frac{1}{R_i C_i} \int V_{in}(t) dt\)

方波 → 三角波
蓝色: \(V_{in}\) (方波输入) | 橙色: \(V_{out}\) (三角波输出，反相，钳位于 ±12V)

反相微分器 · \(V_{out}(t) = -R_d C_d \frac{dV_{in}(t)}{dt}\)

三角波 → 方波
蓝色: \(V_{in}\) (三角波输入) | 紫色: \(V_{out}\) (方波输出，反相，钳位于 ±12V)

📐 理论依据

积分器: \(V_{out}(t) = -\frac{1}{R_i C_i} \int_{0}^{t} V_{in}(\tau) d\tau + V_{out}(0)\)。
方波积分 → 三角波 (线性斜坡)，输出幅值 \(≈\frac{V_{in}}{4f R_i C_i}\)。
微分器: \(V_{out}(t) = -R_d C_d \frac{dV_{in}(t)}{dt}\)。
三角波微分 → 方波 (常值跳变)，输出幅值取决于上升斜率。

⚡ 频率对输出幅值的影响

• 积分器: 增大频率 \(f\) → 积分时间减小 → 输出幅值降低。
增大 \(R_i\) 或 \(C_i\) → 时间常数增大 → 输出幅值降低。
• 微分器: 增大频率 \(f\) → 斜率增大 → 输出幅值增大。
增大 \(R_d\) 或 \(C_d\) → 时间常数增大 → 输出幅值增大。
• 输出超出 ±12V 时将发生饱和钳位，波形顶部被削平。
