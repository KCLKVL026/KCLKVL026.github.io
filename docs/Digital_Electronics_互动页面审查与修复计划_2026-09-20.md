# Digital_Electronics 互动页面审查与修复计划

审查日期：2026-09-20  
范围：`Digital_Electronics/` 的索引页及 30 个教学模块 HTML。  
目的：找出会造成错误教学结论、功能失效或后续维护风险的代码与科学性问题，并给出可验收的修复次序。

## 审查方法与结论边界

- 已检查 31 个 HTML 文件；索引页的 30 个本地模块链接均存在。
- 已将每个内联脚本交给 `node --check`，未发现 JavaScript 语法错误。
- 本文的“科学性”指数字逻辑、时序与数据转换模型是否与页面声称演示的概念一致；它不替代对实体器件、工艺库或 SPICE 模型的测量验证。
- 语法通过不代表行为正确。以下问题多属于算法、状态机或时序模型错误，因此不会被语法检查捕获。

优先级定义：P0 会直接产生错误结果或关键控制无效；P1 会造成概念误导、结果不完整或在常见输入下出错；P2 为可用性、可访问性、可靠性与维护性改进。

## P2：代码质量、可访问性与可靠性

- 计数器页面的频率滑块只改变变量，不立即刷新显示，也不驱动时钟；`Programmable_Counter.html` 的公式写“`Q=N` 时复位”，实现却是直接 `(count+1)%N`，两种模型不一致。应实现运行/停止定时器，或删除频率控件；明确采用同步终端计数或异步清零，并在时序图中显示该过程。
- `T_FlipFlop.html` 在 `T=0` 时仍显示固定的 `f/2^stages` 分频和频谱。应显示“保持、无周期输出”或将频率指标置为 N/A，并让图形与 T 输入一致。
- `Shift_Register.html` 的 PISO 把“首次时钟”隐式当作并行加载，缺少 Load/Shift 控制；应加入显式 `LOAD` 信号，允许在任意时刻重装载。
- D、JK、SR、加法器等页的示例时序多为固定模式，和可点击的当前输入并非同一条信号。应在图例中标明“预设例程”，或让用户输入直接驱动时序、保存事件历史。
- 多数页面用可点击 `div` 代替 `button`，没有键盘操作、焦点样式、`aria-pressed` 或可访问名称；各页还设置了 `user-scalable=no`。应改为原生按钮/输入控件，补齐 ARIA 与键盘测试，并允许移动端缩放。
- 依赖均取自 CDN，未见版本完整性校验、加载失败提示或离线策略。应锁定版本并使用 SRI（可用时），为核心教学逻辑提供依赖失败的可读降级；若项目需要离线课堂环境，应提供本地依赖副本。
- 单文件页面中重复了图表创建、KaTeX 初始化、滑块样式和 DOM 更新套路。可先抽出不含 DOM 的纯逻辑函数（量化、补码、状态转移、K 图覆盖），再逐步复用小型本地脚本，避免一次大规模重构。
- 所有由控件生成的文本目前基本受限于数值或固定字符串，未发现直接的外部输入注入点；不过应继续优先使用 `textContent` 和 DOM 节点拼装，减少不必要的 `innerHTML`。

### P2 本轮完成情况（2026-09-21）

- 已为同步、模 N 与行波计数器加入“自动运行/停止”控制；频率滑块会重启定时器并改变实际时钟周期。模 N 页的公式也改为与实现一致的 `Q⁺=(Q+1) mod N` 同步终端计数模型。
- 已让 T 触发器在 `T=0` 时显示“保持（无分频）”，频谱仅保留时钟基准，不再虚构 Q 的分频谱线。
- 已为 PISO 加入显式、可重复操作的 `LOAD` 使能；`LOAD=1` 在下一个时钟并行装载，`LOAD=0` 才移位。
- 已给固定示例波形补充“预设示例”说明；移除全部页面的 `user-scalable=no`，并为本轮改动的核心控制改用原生按钮、补充 `aria-pressed`、可访问名称和可见焦点。
- CDN 离线降级、本地依赖与跨页面共享脚本属于需要新增依赖资产和改变页面架构的后续工程；本轮未以高风险的批量重构方式处理。

## 推荐实施顺序

1. **建立可回归的逻辑测试。** 将关键算法提取为纯函数：补码加减、setup/hold 判定、门级延迟传播、R–2R 位权、序列状态转移、K 图覆盖。每个函数先写边界表，再改页面。
2. **完成 P0。** 每修一个模块，先固定一个会失败的具体用例，再完成图形、状态卡和公式的一致性更新；不要只修显示文本。
3. **完成 P1 的模型定义。** 对算术、ADC、DAC 和采样页先明确采用无符号/二补码、mid-rise/mid-tread、理想化假设和单位，再实现公式与图表。
4. **完成 P2 的统一质量改进。** 先处理初始化时序与可访问性，再处理依赖降级和重复代码。重构应由测试保护，避免同时修改教学模型和页面框架。
5. **课堂验证。** 让教师按“输入—预测—操作—解释”走完每页的至少三个案例；对显示的公式、真值表、状态卡、波形和提示做逐项一致性检查。

## 验收清单

- 每个模块加载后没有未捕获异常；在正常网络和依赖不可用两种状态下均有可理解反馈。
- 关键页面具备自动回归用例：补码加减、建立保持、静态冒险、行波计数、采样混叠、ADC/DAC、序列检测与 K 图。
- 每一个可调参数会影响它所声称影响的计算或时序；无仅改变数字标签的“伪参数”。
- 任一页面的公式、状态卡、真值表/数值结果与图表来自同一份计算结果，不各自重复实现。
- 所有教学模型都写明假设、单位和适用范围；理想公式不得被标注为任意输入或实际器件的测量结果。
- 所有可点击控制均可通过键盘访问，移动端可缩放，颜色不是传达状态的唯一方式。
