审查日期：2026-09-20
范围：`Analog_Electronics/` 下 20 个 HTML 页面（含导航首页）。本次为源码静态审查：检查了参数映射、计算与绘图数据的对应关系、Chart.js 生命周期、柱状图配置及极端滑块值。所有内嵌脚本均通过 JavaScript 语法编译检查；这**不**表示数值模型或教学现象正确。

## 优先级定义

| 优先级 | 含义 |
| --- | --- |
| P0 | 当前可稳定产生 `NaN`、空图或核心结果不可用，应先修复。 |

## 柱状图：颜色、间距与可读性结论

静态配置中未见自定义 `barPercentage/categoryPercentage`，因此均使用 Chart.js 默认柱宽与类别间距。对当前类别数（2、3 或 4）和 240 px 左右的容器高度而言，**柱体间距本身总体合适，颜色也具有基础的语义区分**：

| 页面 | 结论 | 需要的调整 |
| --- | --- | --- |
| `Power_Amplifier.html` | 黄/绿/红分别对应直流、输出、耗散，辨识度合适；三柱间距也合适。 | 先修 P1 的负耗散；必要时在柱顶显示数值，避免仅凭高度比较。 |
| `Multistage_Amp.html` | 绿/黄/紫三柱配色和三类增益的间距合适。 | 当前受 P0 的 `NaN` 影响，实际不能可靠呈现；修复后应改为“级增益(dB)”与“总增益(dB)”并保留精度。 |
| `Common_Collector_Amp.html` | 绿/黄适合区分输入/输出阻抗，双柱间距合适。 | 对数 y 轴是合理选择；建议在柱顶补 `kΩ/Ω`，避免读者把对数高度误读为线性比例。 |
| `Negative_Feedback_Amp.html` | 四柱配色可区分开闭环、输入/输出阻抗，间距尚可。 | 增益图不能使用线性柱高比较（见 P2）；阻抗图跨度达多个数量级时也应在图例/柱顶注明“对数轴”。 |

结论：不建议仅为“拉开距离”随意增大柱间距；优先修正无效数据与量纲，并为对数/跨数量级数据更换合适的纵轴和数值标注。

## 统一的刷新与实现建议

1. 所有滑块页面建立统一流程：`input → requestAnimationFrame 合并 → 计算 → 原位更新 dataset → chart.update('none')`。目前 PN、齐纳、FET、BJT 已有可复用的 RAF 模式；多页仍在每次输入销毁重建图表。
2. 绘图前检查每一个输出数组、卡片数值是否 `Number.isFinite()`；一旦越界，显示“参数组合无物理解/模型无效”，不要把 `NaN`、负功耗或无限 Q 绘为正常教学结果。
3. 将每页的滑块单位、转换倍率和默认值集中为结构化配置，避免“滑块值 × 常数”散落在函数内造成的单位错误。
4. 对含工作点的页面，明确区分“独立扫描器件特性”与“带电源/电阻的电路工作点”。二者不能同时可调却不求交。
5. 为每页最低限度加入默认值和端点值的数值回归检查：无 `NaN/Infinity`、电压/电流/功率边界合理、Q 点在负载线上、图表数据至少有可见动态范围。
