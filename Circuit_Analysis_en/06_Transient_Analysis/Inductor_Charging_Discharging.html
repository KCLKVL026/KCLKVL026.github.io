Time Constant & Charging/Discharging Rules

⏱️ Time Constant \(\tau\) \(\tau = L/R\) Unit: seconds (s)
📐 RL Circuit Charging/Discharging Formulas (Inductor Current)
Charging phase ( \(v_{\text{in}} = V_m\) ): \(i_L(t) = \frac{V_m}{R} + \left(I_0 - \frac{V_m}{R}\right)e^{-t/\tau}\)
Discharging phase ( \(v_{\text{in}} = 0\) ): \(i_L(t) = 0 + (I_0 - 0)e^{-t/\tau}\)
\(\tau = L/R\) determines transient speed: after \(1\tau\) current rises/drops ~63.2%, after \(5\tau\) essentially reaches steady state.
The ratio of square wave frequency to \(\tau\) affects the inductor current waveform shape (exponential charging/discharging).
Inductor current unit: milliamps (mA), displayed values in the chart are converted to mA.
💡 Key observations: When period \(T \ll \tau\), current charging/discharging is incomplete, appearing as an approximate triangle wave; when \(T \gg \tau\), current can fully charge or discharge, waveform approaches a square wave.
Current default parameters: R=500Ω, L=500mH → τ=0.001s, period T=0.02s, half-period 0.01s (10τ), charging/discharging ~99.995%, current nearly fully charges/discharges. Steady-state current \(I_{max}=V_m/R = 2\,\text{mA}\).

🔍 Waveform Observation Points

• Square wave rising edge: inductor current begins exponential rise toward \(V_m/R\) (mA).
• Square wave falling edge: inductor discharges through resistor, current decays exponentially toward 0.
• Larger time constant \(\tau = L/R\) means slower charging/discharging, more "sluggish" waveform.
• Adjust frequency: at low frequencies, current can fully charge/discharge; at high frequencies, waveform appears as approximate triangle wave.

⚙️ Parameter Influence Rules

\(i_L(t)\) charging rate is determined by \(\tau = L/R\).
Increasing \(L\) or decreasing \(R\) → \(\tau\) increases → charging/discharging slows down, waveform distortion becomes more pronounced;
Increasing square wave frequency \(f\) → period decreases → charging/discharging time shortens, current amplitude decreases.
Amplitude \(V_m\) changes steady-state current value \(V_m/R\) (mA), but not the time constant.
