Theoretical Basis

In a three-phase four-wire system, neutral current \(I_N = I_A + I_B + I_C\) (phasor sum).
When load is balanced, \(I_N = 0\); when unbalanced, \(I_N \neq 0\).
Without a neutral line (three-phase three-wire), the neutral displacement voltage is:
\(V_{NN'} = \frac{V_A Y_A + V_B Y_B + V_C Y_C}{Y_A + Y_B + Y_C}\) where \(Y = 1/Z\) is admittance.

Characteristic Interpretation

The neutral line forces the load neutral point potential to equal the supply neutral point, keeping each phase load voltage symmetric.
If the neutral line breaks, unbalance causes severe voltage deviation across phases (some phases over-voltage, some under-voltage).
Adjust Phase A load to observe: I_A changes in the phasor diagram, I_N appears, V_NN' deviates from the origin.
