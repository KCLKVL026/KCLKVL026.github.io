# 模拟电子技术辅助教学

面向电子信息、电气工程、自动化等相关专业的**交互式仿真教学平台**，通过动态可视化帮助理解模拟电子技术核心概念。所有模块支持参数实时调节、波形/曲线即时更新，适合课堂演示与学生自主探索。

> 共 **19 个交互仿真模块**，按知识体系分为五大类。

## 模块索引

### 1. 半导体器件
| 模块名称 | 简介 |
|:---|:---|
| PN结与二极管 | 肖克利方程 V-I 特性曲线，温度效应与偏置状态分析 |
| 稳压二极管 | 齐纳击穿特性，并联稳压电路 V_out vs V_in 曲线 |
| 双极型晶体管特性 | BJT 输入/输出特性曲线族，Q 点分析与 Early 效应可视化 |
| 场效应管特性 | JFET/MOSFET 转移特性与输出特性，平方律模型与跨导 |

### 2. 基本放大电路
| 模块名称 | 简介 |
|:---|:---|
| 共射极放大电路 | DC 偏置、交流小信号放大、负载线与旁路电容对增益的影响 |
| 共集电极放大电路 | 射极跟随器：高输入阻抗、低输出阻抗、单位电压增益 |
| 共基极放大电路 | 同相放大、极低输入阻抗、优异高频特性 |
| 共源极放大电路 | FET 共源放大器 DC 偏置与交流小信号分析 |
| 多级放大电路 | CE-CE/CE-CC 级联与差分对，逐级增益叠加与阻抗匹配 |

### 3. 集成运算放大器
| 模块名称 | 简介 |
|:---|:---|
| 理想运放基础 | 反相/同相/跟随器三种组态，虚短虚断概念与饱和削波 |
| 运放线性应用 | 求和/差分/积分/微分/仪表放大器，五种子模式交互 |
| 有源滤波器 | Sallen-Key 二阶 LP/HP/BP，幅频与相频伯德图响应 |
| 运放非线性应用 | 比较器、施密特触发器迟滞回线、方波-三角波发生器 |

### 4. 反馈与频率响应
| 模块名称 | 简介 |

| 功率放大电路 | A类/B类/AB类功放效率对比，交越失真与功率分配 |

### 5. 信号产生与电源
| 模块名称 | 简介 |
|:---|:---|
| 正弦波振荡器 | 文氏桥/RC移相/Colpitts 起振瞬态分析，Barkhausen 判据 |
| 非正弦波发生器 | 方波/三角波/锯齿波发生器与 555 定时器，充放电波形展示 |

## 🛠️ 技术栈

- **HTML5 / CSS3 / JavaScript (ES6)** — 无构建工具，纯浏览器运行
- **Tailwind CSS v3** — 响应式 UI 框架
- **Chart.js v4.4.0** — 交互式图表绘制
- **KaTeX v0.16.9** — 数学公式渲染

每个模块均为独立的 HTML 文件，所有依赖通过 CDN 加载，无需安装任何工具即可在浏览器中打开使用。

## 🚀 使用方式

1. 克隆或下载本仓库
2. 直接用浏览器打开 `index.html` 进入导航主页
3. 点击任意模块卡片，在新标签页中打开对应仿真页面
4. 拖动滑块实时调整参数，观察图表和数据的即时变化

或直接访问 GitHub Pages 在线体验（部署后添加链接）。
